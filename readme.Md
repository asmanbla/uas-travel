# 🌍 TravelKu - Website Pemesanan Paket Wisata

## Deskripsi Aplikasi

**TravelKu** merupakan website sederhana yang dibuat untuk memudahkan pengguna dalam mencari informasi destinasi wisata dan melakukan pemesanan paket wisata secara online. Website ini dikembangkan sebagai tugas mata kuliah Pemrograman Web dengan memanfaatkan teknologi HTML, CSS, dan JavaScript.

Website ini memiliki tampilan yang responsif sehingga dapat diakses dengan baik melalui komputer, tablet, maupun smartphone.

---

## Fitur Aplikasi

* Halaman Login
* Halaman Beranda (Home)
* Halaman Profil Aplikasi
* Halaman Daftar Destinasi Wisata
* Halaman Form Booking Paket Wisata
* Tampilan Responsif (Desktop, Tablet, dan Mobile)
* Navigasi Antar Halaman

---

## Teknologi yang Digunakan

* HTML5
* CSS3
* JavaScript
* Google Fonts (Poppins)

## Cara Menjalankan Program

1. Unduh atau clone repository proyek.
2. Buka folder proyek menggunakan Visual Studio Code atau editor lainnya.
3. Jalankan file **login.html** atau **index.html** menggunakan browser.
4. Website siap digunakan.
